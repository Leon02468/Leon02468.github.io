UNITY PRACTICE & DEVELOPMENT

Bee-Networld

Unity C# JSON Puzzle Network Level Design

Description

Bee-Networld is a 2D puzzle-platformer developed in Unity that introduces IP addressing concepts through interactive gameplay.

Players navigate through levels by moving, jumping, and climbing ladders while configuring IP addresses using binary-based HoneyBits. The objective is to match the configured IP address with those assigned to incoming bees, completing challenges while managing time and score requirements.

The game combines platforming mechanics with basic networking concepts, turning IP address configuration into an interactive puzzle experience.

Contributions

  • Implemented core gameplay mechanics, including player movement, jumping, ladder climbing, and HoneyBit interactions.
  • Designed and created 2D pixel art character sprites and animations.
  • Developed gameplay systems for IP address matching, bee queues, timers, and score-based objectives.
  • Worked on level design and JSON-based level configuration to define IP address challenges and level parameters.
  • Implemented and refined gameplay UI components to support player interaction and progression.
