# Le Duc Minh — Unity Game Developer Portfolio

## File structure

- `index.html` — page content and semantic structure.
- `styles.css` — colors, layout, typography, cards, and responsive rules.

## Preview locally

Keep both files in the same folder, then open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a public repository named `Leon02468.github.io`.
2. Upload both `index.html` and `styles.css` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save and wait for deployment.
6. Website URL: https://leon02468.github.io/
